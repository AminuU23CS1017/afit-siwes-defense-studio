# AFIT SIWES Defense Studio

Study technical topics, practise defense questions and prepare for a SIWES presentation.

Hosted version: https://afit-siwes-defense-ayo.ayomideaminu.chatgpt.site

The existing hosted version requires owner access. This repository shares the source code; it does not change access to the hosted site.

The public source uses a sample student profile instead of personal training details. Saved study progress remains in the browser and is not included.

## Run locally

```sh
python3 -m http.server 8000 --directory dist
```

Open http://localhost:8000. No build step is required.
